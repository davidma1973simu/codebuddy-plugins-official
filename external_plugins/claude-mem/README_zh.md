## 快速开始

在终端中启动一个新的 CodeBuddy Code 会话并输入以下命令：

```
> /plugin marketplace add thedotmack/claude-mem

> /plugin install claude-mem
```

重启 CodeBuddy Code。之前会话的上下文将自动出现在新会话中。

**核心特性：**

- 🧠 **持久化记忆** - 上下文在会话间保持存活
- 📊 **渐进式展示** - 分层记忆检索，可见 token 成本
- 🔍 **基于 Skill 的搜索** - 使用 mem-search skill 查询项目历史
- 🖥️ **Web 查看器 UI** - 实时记忆流，访问地址 http://localhost:37777
- 💻 **CodeBuddy Desktop Skill** - 从 CodeBuddy Desktop 对话中搜索记忆
- 🔒 **隐私控制** - 使用 `<private>` 标签排除敏感内容的存储
- ⚙️ **上下文配置** - 精细控制注入的上下文内容
- 🤖 **自动运行** - 无需手动干预
- 🔗 **引用** - 使用 ID 引用过去的观察（通过 http://localhost:37777/api/observation/{id} 访问或在 http://localhost:37777 的 web 查看器中查看所有内容）
- 🧪 **Beta 频道** - 通过版本切换尝试实验性功能，如无限模式

## 工作原理

**核心组件：**

1. **5 个生命周期 Hooks** - SessionStart、UserPromptSubmit、PostToolUse、Stop、SessionEnd（6 个 hook 脚本）
2. **智能安装** - 缓存依赖检查器（pre-hook 脚本，不是生命周期 hook）
3. **Worker 服务** - 端口 37777 上的 HTTP API，具有 web 查看器 UI 和 10 个搜索端点，由 Bun 管理
4. **SQLite 数据库** - 存储会话、观察、摘要
5. **mem-search Skill** - 具有渐进式展示的自然语言查询
6. **Chroma 向量数据库** - 混合语义 + 关键词搜索，实现智能上下文检索

详见[架构概述](https://docs.claude-mem.ai/architecture/overview)。

## MCP 搜索工具

CodeBuddy-Mem 通过 **4 个 MCP 工具**提供智能记忆搜索，遵循 token 高效的 **3 层工作流模式**：

**3 层工作流：**

1. **`search`** - 获取包含 ID 的紧凑索引（~50-100 tokens/结果）
2. **`timeline`** - 获取有趣结果周围的时间上下文
3. **`get_observations`** - 仅获取已过滤 ID 的完整详细信息（~500-1,000 tokens/结果）

**工作原理：**
- CodeBuddy 使用 MCP 工具搜索您的记忆
- 从 `search` 开始获取结果索引
- 使用 `timeline` 查看特定观察周围发生的事情
- 使用 `get_observations` 获取相关 ID 的完整详细信息
- 通过在获取详细信息前过滤，**节省约 10 倍 token**

**可用的 MCP 工具：**

1. **`search`** - 使用全文查询搜索记忆索引，按类型/日期/项目过滤
2. **`timeline`** - 获取特定观察或查询周围的时间上下文
3. **`get_observations`** - 按 ID 获取完整观察详细信息（始终批量处理多个 ID）
4. **`__IMPORTANT`** - 工作流文档（CodeBuddy 始终可见）

**使用示例：**

```typescript
// 步骤 1：搜索索引
search(query="authentication bug", type="bugfix", limit=10)

// 步骤 2：审查索引，识别相关 ID（例如 #123、#456）

// 步骤 3：获取完整详细信息
get_observations(ids=[123, 456])
```

详见[搜索工具指南](https://docs.claude-mem.ai/usage/search-tools)。

## 系统要求

- **Node.js**：18.0.0 或更高版本
- **CodeBuddy Code**：支持 plugin 的最新版本
- **Bun**：JavaScript 运行时和进程管理器（如果缺失会自动安装）
- **uv**：用于向量搜索的 Python 包管理器（如果缺失会自动安装）
- **SQLite 3**：用于持久化存储（已捆绑）
